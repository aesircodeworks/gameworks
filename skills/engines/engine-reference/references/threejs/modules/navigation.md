# Three.js Navigation — Quick Reference

Last verified: 2026-09-11 | Engine: r186

**Bring your own.** three.js has no navmesh or crowd.
Community options listed in the official plugins page include yuka,
three-pathfinding, and recast-navigation-js. Pin any choice in
`docs/technical-preferences.md` Allowed Libraries only when the project
actually integrates it.
